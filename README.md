# Squeek Circuit

A small, independent Squeekchain community puzzle. Rotate the pipes to carry the wheel's energy to three burrows. The official public Sepolia API supplies the seed for each reproducible board.

## Play locally

Node.js 22 or newer. No package installation, API keys or wallet required.

```sh
node serve.mjs
```

Open http://127.0.0.1:4174. Run `node --test engine.test.mjs` for the engine checks.

## How to play

- Tap or click a pipe to turn it clockwise. Shift-click turns it back.
- Connect the wheel's input on the left to all three burrows on the right.
- Tab and Enter work on every tile; arrow keys move between tiles. P pauses.
- Hints place a tile in a valid solution orientation and deduct 150 points.
- Fewer turns and a shorter time improve your score. Personal records stay in your browser.
- Reset replays the same board; Load latest round fetches new data. If the round is unchanged, a numbered local variant is generated from the same source.
- Leaving the tab pauses the shift. A new board or reset asks before discarding an unfinished puzzle.

## Actual Squeekchain integration

The browser fetches `https://api.squeekchain.com/v1/core`, a read-only public API. Schema version 1, available status, chain ID 11155111, Sepolia target, the Core address and the unsigned integer fields used in generation are checked before accepting a response.

The board seed combines an algorithm version, the Core address, settled round, cumulative block units, difficulty and a variant number. Large source numbers remain strings; safe-block comparisons use BigInt. A randomized spanning tree guarantees a connected solution, then its tiles are scrambled. The seed remains fixed while the player solves the puzzle. No contract addresses are hardcoded.

The source panel shows the source block, round, fetched time and settlement time, with links to the Core and settlement transaction. Data is API-reported, not independently verified against Ethereum. The source panel and this README describe that boundary explicitly. The animated wheel and lit circuits are game graphics, not claims about the hamster's current motion or actual mining.

Initial API failures activate an explicitly labeled practice board. Failed refreshes and older safe-block snapshots preserve the current puzzle. This game does not poll continuously.

## Hosting

The production application is `index.html`, `style.css`, `game.mjs`, `engine.mjs` and `favicon.svg`. Serve these files from GitHub Pages, Render Static Sites or any static host. There is no build step. Relative file references support repository subpaths. Google Fonts are optional; system fonts are used if unavailable.

The private Sites preview manifest, when present locally, is not needed to run or host the public GitHub project.

## Boundaries

This is an independent community game, not an official Squeekchain product or approved whitelist competition. Playing does not mint SQK, spend money or award a Genesis badge. Scores are local and can be edited by the player; there is no global leaderboard or reward claim. A submitted project remains subject to the current Genesis eligibility and repository-control rules. Verification challenge files must come from the genuine submission UI and are never generated by this game.

## Files

- `engine.mjs` — validated source parsing, deterministic board generation, connectivity and scoring.
- `game.mjs` — browser controls, public API integration, hints, pause and local records.
- `index.html`, `style.css`, `favicon.svg` — responsive UI and original vector artwork.
- `engine.test.mjs` — generation, solve, topology, source and replay checks.
- `serve.mjs` — dependency-free local server.
